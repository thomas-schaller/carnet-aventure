# Carnet d'aventures

## Modèle

Une aventure est composée de plusieurs scènes, d'intrigues et de personnageNonJoueurs non joueurs.
Il y a trois types de scènes :
 - scène attendue,
 - scène altérée,
 - scène d'interruption.



## Objectif


L'interface UI permet de :

- de créer de nouvelles aventures,
- d'ouvrir et supprimer des aventures existantes,
- d'ajouter des scènes à une aventure,
- de modifier les scènes d'une aventure
- de lister les personnageNonJoueurs d'une aventure,
- d'ajouter et modifier un personnageNonJoueur d'une aventure,
- de lister les intrigues d'une aventure,
- d' ajouter ou modifier une intrigue à une aventure.
- de poser des questions sous la forme oui / non afin d'aider à la rédaction d'une scène,
- de visualiser et modifier les personnageNonJoueurs joueurs.
- de générer des mots aléatoires,
- de lancer des dés,
- de logger les évènements d'une scène.
